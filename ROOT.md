## НЕ ТРОГАТЬ
- [downloader] число соединений к `events-delivery-records.webinar.ru` суммарно не выше ~320: на 384 — 20% таймаутов, на 512 — 85–88% ошибок (ConnectTimeout/ReadTimeout), скорость 0,4 МБ/с (замер 25.09, воспроизведено дважды)
- [downloader] HTTP/2 не включать: 256 потоков по HTTP/2 = 0,65 МБ/с против 5,04 по HTTP/1.1 (замер 25.09) — все запросы идут через одно TCP-соединение
- [downloader] `media.mix_filter`: `normalize=0` и `adelay=…:all=1` — без них тихий звук или сдвиг только левого канала
- [downloader] `pipeline._drain`: запись сегмента через `.part` + `replace` — на этом держится докачка
- [downloader] `pipeline.job_folder`: если `job.folder` уже задан, он возвращается как есть — иначе перезапуск уедет в новую папку и докачка сломается
- [rust-core] `cache.rs`: уникальное временное имя в `write_atomic` — общий `.part` роняет загрузку при дублях сегмента
- [rust-core] `fetch.rs`: приоритетная очередь с исходным приоритетом при повторе — замена на «задача на сегмент + семафор» вернёт простой сведения
- [rust-core] `mix.rs`: `starts_at` у входа — без него микшер ждёт первую порцию дорожки, которая начинается через час, и встаёт
- [rust-core] `encode/aac.rs`: `BufferList` вложенной структурой — плоская раскладка ломает выравнивание указателя (AudioBufferList)
- [rust-server] `view.rs`: один замок на оператор — два `lock()` одного мьютекса в одном выражении дают взаимоблокировку
- [scripts] `start.command`: перебор `python3.12 → … → python3` с проверкой `print(...)` — голый `python3` на этой машине битый и молчит
- [server] `app.mount("/", StaticFiles…)` — строго последним, иначе перекроет `/api` и `/files`
- [server] `store.launch`: `job.reset()` сохраняет `folder` — на этом держится перезапуск в ту же папку
- [ui] `app.js`: слушатель `toggle` на фазе перехвата (`true`) — событие не всплывает, без него журнал закрывается при перерисовке

## Техдолг
- [downloader] определение экрана — эвристика по модулю `screensharing*` в eventLogs; в тестовой записи экрана не было, проверить не на чем
- [downloader] RESOLUTION в master-плейлисте не совпадает с кадром (заявлено 640×480, реально 640×360 — ffprobe 25.09); в имени файла «480p»
- [downloader] ретраи: 6 попыток с паузой до 20 с; при 403/404 — сразу ошибка. Порог подобран без замеров потерь
- [downloader] `_work/` занимает ~2× аудио (917 МБ на запись 24554640907, 25.09): сегменты + склеенные `a.mp4`; сегменты нужны для докачки, чистится кнопкой «Удалить промежуточные»
- [downloader] RAM процесса растёт с числом потоков: 120 МБ на 64, 310 МБ на 256 (замер 25.09) — терпимо, но держать в уме
- [downloader] скорость упирается в канал пользователя: на 256–320 потоках 5,0–5,5 МБ/с при потолке канала 4,8–6,1 МБ/с на одно соединение к Cloudflare (замер 25.09); выше не прыгнуть без другого канала
- [downloader] `bytes_total_est` — оценка по среднему размеру сегмента, точного размера заранее нет (HEAD на тысячи сегментов дорого)
- [rust-core] дорожки участников (.m4a) режутся по границам сегментов (~13 с): байты копируются без перекодирования; смещения в FCPXML/EDL это учитывают (`start`/source in)
- [rust-core] EDL — однодорожечный формат: все клипы подряд списком; полная мультикам-раскладка только в FCPXML
- [rust-core] ffmpeg на выводе в null пишет «non monotonically increasing dts» и для исходного fMP4 с сервера — свойство VFR-потока, не перепаковки (проверено 26.09)
- [rust-core] камеры в тестовой записи — 320×180 (SMALL), 25 fps; заявленное в плейлисте 640×480 не соответствует кадрам
- [rust-core] ожидание микшера на реальном сервере не опускается ниже ~1,5× p50: медленный объект медленный для всех запросов (замер 25.09: два дубля одного сегмента вернулись вместе с оригиналом через ~28 с); на моке с зависшим соединением — 1,1× медианы
- [rust-core] метрика «простой» зависит от способа: по файлу (Gate) 11,5–13,7 с = 1,5–1,9× p50 во всех 3 прогонах CLI; по отсутствию движения сведения в интерфейсе 11,1–17,6 с = 1,4–2,1× p50 (2 прогона, один на 2,09×)
- [rust-core] Opus: `use_cbr = true` обязателен — в VBR opus-rs игнорирует битрейт (24 кбит/с → 53–74 кбит/с, замер 25.09)
- [rust-core] частота дорожек только 48 кГц (иначе ошибка); ресемплинга входа нет — на реальных записях другой не встречалась
- [rust-core] AudioToolbox FFI написан вручную (без bindgen); проверен только на macOS arm64
- [rust-server] `ui/` лежит вне крейта (`include_bytes!("../../ui/…")`) — для `cargo publish` понадобится копия внутри крейта или build.rs
- [rust-server] проценты: пока идёт загрузка — по сегментам на диске, последние 3% — сведение
- [rust-ui] headless Chrome на macOS не сужает окно меньше ~500 px — мобильную вёрстку проверять через iframe 390 px
- [scripts] Homebrew `python@3.13` 3.13.7 сломан: бинарник `python3.13` — пустой файл 0 байт, `python3` молча ничего не делает (25.09). Лечится `brew reinstall python@3.13`; проект живёт на 3.12, поэтому не чиним
- [scripts] `caffeinate -i` не спасает от сна при закрытой крышке — крышку во время длинной загрузки не закрывать
- [server] состояние задач только в памяти процесса + history.json; при падении сервера теряется прогресс с момента последнего автосохранения (≤2 с)
- [server] `GET /api/jobs` отдаёт полный журнал и дорожки каждой задачи на каждом опросе — пока история короткая, не мешает
- [ui] нет тестов JS; синтаксис проверен `node --check`, поведение — вручную
