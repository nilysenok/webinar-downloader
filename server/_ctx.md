# server
Слой: БЭКЕНД

## НАЗНАЧЕНИЕ
Локальный HTTP-сервер дашборда: принимает задачи, гоняет `downloader.run` в фоне, хранит историю,
раздаёт интерфейс `ui/` и готовые файлы. Только 127.0.0.1.

## КОНТРАКТ
- запуск: `.venv/bin/python -m server.app` (порт `PORT`, по умолчанию 8765)
- `POST /api/analyze {url}` → запись и дорожки с вариантами видео (без URL рендишнов)
- `POST /api/jobs {url, mode, quality, streams, workers}` → 201 + задача; для av/video `streams` обязателен
- `GET /api/jobs` → задачи новые сверху; + `speed, eta, progress, bytes_total_est, work_size, outputs[].exists`
- `POST /api/jobs/{id}/cancel | restart | reveal | clean`, `DELETE /api/jobs/{id}` (409 для активной)
- `GET /files/{id}/{n}[?dl=1]` → n-й итоговый файл (Range поддерживается)
- `GET /` и статика — `ui/`
- `history.json` в корне: список `Job.to_dict()`; автосохранение раз в 2 с, пока есть активные

## ИНВАРИАНТЫ
- обработчики, запускающие задачи (`create`, `restart`), — `async def`
- после рестарта сервера активные задачи становятся `interrupted`, «Продолжить» докачивает
- «Удалить из истории» не удаляет файлы; «Удалить промежуточные» трогает только `_work/` внутри `downloads/`
- пока есть активная задача, живёт `caffeinate -i -w <pid сервера>`
