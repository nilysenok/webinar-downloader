# rust-ui
Слой: ФРОНТЕНД

## НАЗНАЧЕНИЕ
Интерфейс `webinarip serve` (`../webinarip/ui/`): ваниль HTML/CSS/JS, 23 КБ, встроен в бинарник. Вариант A: один столбец, экран меняет состояние. Имя модуля `rust-ui` — `ui/` занят Python-версией.

## КОНТРАКТ
- файлы: `index.html`, `style.css`, `app.js` (события, опрос), `view.js` (отрисовка), `fmt.js` (форматы, API)
- ожидание: крупное поле в фокусе, Enter — старт, режимы, «Параметры ▸» (формат, качество, отрезок, дорожки-чипы, session-id), «Недавние»
- вставка ссылки → probe: название · длительность · дорожки · «прогрев N%»
- режимы «видео» и «оба» активны; в «Параметрах ▸ Ещё»: дорожки участников, монтажный проект, MP4 (ffmpeg, медленно); итог «N файлов · размер»
- качество: «речь · моно» (по умолчанию) | «стерео» | «для расшифровки · 16 кГц»; под гистограммой «ожидание ≤ N с» (простой микшера)
- загрузка: шапка в одну строку, крупные цифры (МБ/с · осталось · %), на сведении «×N к реальному времени», степпер, тонкие полосы дорожек на шкале записи, плеер, гистограмма задержек p50/p99, «ещё N в очереди», «Отменить»
- готово: «заняло · файл · 100%», «Показать в папке»
- опрос `/api/state`: 0,5 с при работе, 2 с в покое

## ИНВАРИАНТЫ
- без фреймворков, сборщиков, веб-шрифтов и иконочных библиотек; всё ≤ 60 КБ до сжатия
- тёмная тема по умолчанию, светлая — по `prefers-color-scheme`
- один экран без прокрутки на 1280×800 и 390×844 (проверено скриншотами 25.09)
- любой текст с сервера — через `esc()`; session-id в localStorage не пишется
