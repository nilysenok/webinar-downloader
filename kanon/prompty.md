# Готовые промпты

Часть канона v3, перенесено из главного файла без изменений.

**Развернуть канон в новом или старом проекте:**
```
Разверни в этом репозитории систему КАНОН по файлу KANON_kak_my_vedem_proekty.md.
Этап 1 — разведка, ничего не меняя: что за проект по коду, модули (≤10) с делением на ФРОНТЕНД/БЭКЕНД, что работает, что сломано, незавершённое, файлы >200 строк, вопросы ко мне списком. Стоп, жди моего «да».
Этап 2 — создай pravila.md, spec.md, arhiv.md, roadmap.md, <модуль>/_ctx.md по шаблону, сборщик xtask (md → ROOT.md + dashboard.json → dashboard.html, валидатор --check). Неизвестное — в ❓, не выдумывай.
```

**Начать сессию после `/clear`:**
```
Прочитай pravila.md, ROOT.md и _ctx.md модуля <имя>. Скажи в 5 строках, где мы и что дальше.
```

**Закрыть сессию:**
```
Закрываем сессию: обнови _ctx.md затронутых модулей, закрытое — в arhiv.md, решения — печатями, вопросы — в ОТКРЫТО. cargo xtask, коммит, push. Покажи, что изменилось в ROOT.md.
```

**Тест восстановления (раз в месяц, 10 минут):**
```
Не читая код, только по md: что сейчас главное, какие три ближайших задачи со сроком, что запрещено трогать?
```
Ответы верны — система работает. Нет — в md не хватает контекста, дописываем.
