# Данные, кэш, умолчания

Часть канона v3, блок владельца №2.

**ОД-11.** Никаких режимов, воспроизводящих исправленные ошибки: старые результаты — в архив с хэшами, эталоны пересчитываются на исправленном коде.

**ОД-12.** Каждое изменение данных, ключей кэша, параметров по умолчанию — отдельный PR с тестом, который падает без правки, и строкой «что изменилось в числах».

Умолчание по ПР-16 (27.10): в проектах, где работают прямо в `main` без PR, «отдельный PR» = отдельный коммит с этим тестом и строкой «что изменилось в числах».
