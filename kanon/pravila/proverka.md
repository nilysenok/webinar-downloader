# Проверка кода и результатов

§5 канона v23. Путь `rules/mutations.md` из §5.1 — это `kanon/pravila/mutations.md`.

**§5.1.** **Тест с подложенной ошибкой** (мутация) обязателен для каждого PR, меняющего пайплайн: тест должен падать на мутации и проходить на правке. Список обязательных мутаций по теме хранится в `rules/mutations.md` (сдвиг входа, касание уровня, порядок событий в баре, комиссия на границе, ключ кэша, N в поправке).

**§5.2.** **Разделение ролей** (автор / тестировщик / ревьюер) и **перепроверка родителем** — см. §2.

**§5.3.** **Быстрый и медленный слой**: любая оптимизация скорости сверяется с эталонным медленным путём побайтно (или с объявленным допуском) на фиксированном наборе точек; сверка — в CI.

**§5.4.** **Статус результата в каждой таблице**: «до аудита / после аудита / разработка / тест», версия кода, хэш входов — в шапке файла, не в сопроводительном письме.

**§5.5.** **Проверка по известному ответу**: синтетические данные, где правильный результат известен, для каждого модуля (исполнение сделок, метрики, бутстрап, DM).
