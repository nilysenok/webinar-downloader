# Связь с владельцем

§6 канона v23. Журнал решений — `docs/resheniya/resheniya.md` (локальный: блоки дословные).

**§6.1.** Блоки владельца нумеруются (дата-время или сквозной номер); главная сессия отвечает квитанцией «принят блок N» до исполнения; журнал решений — файл только для добавления; блок без квитанции считается не дошедшим.

**§6.2.** Решения владельца пишутся дословно, толкование — отдельной строкой; при расхождении приоритет у дословного.

**§6.3.** Вопрос владельцу — только с умолчанием и сроком («если нет ответа до T, делаю X»); вопросов в одном сообщении — не больше трёх, с номерами.

**§6.4.** Отчёт владельцу: результат первой строкой; что не сделано; что отступило; что требует решения; без пересказа задания.

**§6.5.** Время — только по часам машины, где идёт работа.

**§6.6.** Чувствительные данные (личные, финансовые, служебные) — в отдельном файле вне репозитория; агенты получают их только через переменные окружения или по явной команде.

## Ж-004 · журналы и квитанции (Э1)

**Ж4-1.1.** Три файла вместо одного плана, в `docs/resheniya/`:
- `resheniya.md` — только блоки владельца, дословно, с номером Ж-NNN, временем по часам машины и строкой-квитанцией «принят Ж-NNN, ЧЧ:ММ» сразу под блоком. Только добавление; правка существующих строк запрещена [Х: PreToolUse на Edit этого файла — разрешён только append; проверка: diff не удаляет и не меняет строки].
- `ispolnenie.md` — по каждому Ж-NNN: что сделано, PR, коммиты, что не сделано, отступления.
- `tolkovaniya.md` — умолчания и толкования дирижёра с номером блока, к которому относятся; владелец может отменить толкование отдельным блоком.
Старый план — в архив, ссылка из `resheniya.md`.

_Здесь: [Х] `docs/resheniya/resheniya.md`, `ispolnenie.md`, `tolkovaniya.md` (локально); старый журнал — `arhiv/zhurnal_do_Zh-004.md`; хук PreToolUse «только дописывать» на все три файла._

**Ж4-1.2.** Правило квитанции [Т+М]: блок без строки-квитанции считается не дошедшим; главная сессия пишет квитанцию до начала исполнения; советник владельца сверяет свой журнал с `resheniya.md` раз в день — расхождение = инцидент.

_Здесь: [Т+М] квитанция «принят Ж-NNN, ЧЧ:ММ»; сверка — `scripts/kanon/sverka_blokov.py`; хук SessionStart показывает блоки без квитанции; советника владельца в этом проекте нет — сверяет владелец._

**Ж4-1.3.** Вопросы владельцу [Ш]: не больше трёх в сообщении, каждый с номером, умолчанием и сроком («если нет ответа до T — делаю X»). Шаблон в `templates/vopros.md`.

_Здесь: [Ш] `templates/vopros.md`._

**Ж4-1.4.** Трассируемость [Х+CI]: описание каждого PR содержит строку `Blok: Ж-NNN` и `Punkt: <документ>#<раздел>`; хук на `gh pr create`/`gh pr merge` отказывает без неё; каждая таблица результатов в шапке несёт `blok`, `commit`, `vhody_sha`.

_Здесь: [Х] хук PreToolUse на `gh pr create`/`gh pr merge` отказывает без `Blok:` и `Punkt:`. Таблиц результатов в проекте нет (результат — медиафайлы) — шапка `blok/commit/vhody_sha` неприменима (Ж-005)._
