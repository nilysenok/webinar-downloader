# ui
Слой: ФРОНТЕНД

## НАЗНАЧЕНИЕ
Интерфейс загрузчика в браузере: ввод ссылки, выбор режима/качества/потоков, прогресс текущих загрузок,
история прошлых. Работает только через `server` (CORS и запись на диск — не из браузера).

## КОНТРАКТ
- `ui/index.html` + `style.css` + ES-модули без сборки: `app.js` (вход, опрос, действия), `form.js`, `board.js`, `history.js`, `util.js`
- опрос `GET /api/jobs`: 1 с при активных задачах, 3 с без них
- кнопки — через `data-act` + `data-id` и один делегированный обработчик: cancel, restart, reveal, clean, delete, play
- localStorage: только последний режим и число потоков

## ИНВАРИАНТЫ
- история перерисовывается только при изменении данных — клики и открытый журнал не сбиваются
- любой текст с сервера — через `esc()`
- режим «аудио» не требует анализа записи; av/video — без выбранного потока не отправляются
