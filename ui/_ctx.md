# ui
Слой: ФРОНТЕНД

## НАЗНАЧЕНИЕ
Интерфейс загрузчика в браузере: ссылка → «Аудио» или «Видео» → «Скачать», прогресс текущих загрузок,
история прошлых с прослушиванием и просмотром. Работает только через `server` (CORS и запись на диск — не из браузера).

## КОНТРАКТ
- `ui/index.html` + `style.css` (основа, форма, история, плеер) + `board.css` (карточка, подробности, шкала)
- ES-модули без сборки: `app.js` (вход, опрос, действия), `form.js`, `board.js` (карточка загрузки), `more.js` (подробности: цифры, шкала участников, журнал), `history.js`, `player.js`, `util.js`, `icons.js` (единый набор иконок; в `index.html` — `<i data-icon>`, их подставляет `hydrate()`)
- форма шлёт `POST /api/jobs {url, mode}`: mode = `audio | av`; камеры, качество, соединения — по умолчанию сервера
- после вставки ссылки — сводка `POST /api/analyze`: название · длительность · участников · камер; отправка её не ждёт
- карточка загрузки: %, этап словами, шаги, скорость / скачано / прошло, «Отменить» (с подтверждением); остальное — в свёрнутых «Подробностях»
- история: главное действие в строке («▶ Слушать» MP3, «▶ Смотреть» общий экран, «Продолжить» для прерванных), «В Finder»; файлы, «Скачать заново», «Удалить промежуточные», «Убрать из списка», «Журнал и цифры» — под кнопкой «Подробнее» (видна и на телефоне); статус (Ошибка / Прервано) — первым в строке под названием, не в конце названия (29.09)
- плеер: MP3 — полоса внизу, общий экран (H.264) — окно поверх страницы, Esc закрывает
- `favicon.svg` — фавиконка: красный (`--accent` #e3262f) скруглённый квадрат, белая стрелка «скачать» в лоток; SVG, читается и в 16 px; подключена в `<head>` (тест `tests/test_ui.py`)
- опрос `GET /api/jobs`: 1 с при активных задачах, 3 с без них
- кнопки — через `data-act` + `data-id` и один делегированный обработчик: cancel, restart, reveal, clean, delete, play
- localStorage: только последний режим
- все дополнительные действия и техника — под «Подробнее»: в строке истории и в карточке загрузки одно и то же слово (29.09, владелец: «все допы в подробнее»)

## ИНВАРИАНТЫ
- иконки — только из `icons.js` (24×24, линия 2, скруглённые концы; «play» — заливкой); текстовые символы ▶ ↓ ✕ › вместо иконок запрещены — разная толщина и базовая линия в разных шрифтах (29.09, тест `test_ui.Icons`)
- красный — только действия и выбранное: «Скачать», главная кнопка строки, рамка и плитка выбранного режима; плитки записей в истории нейтральные (29.09)
- история перерисовывается только при изменении данных — клики и открытые «Подробности» не сбиваются
- открытые `<details>` помнятся по ключу `data-log` = `<id>:more` / `<id>:log`
- любой текст с сервера — через `esc()`
- отправка не требует анализа записи ни в одном режиме

## ТЕХДОЛГ
- нет тестов JS; синтаксис проверен `node --input-type=module --check`, поведение — скриншотами headless Chrome (28.09)
- отдельные файлы камер (VP9) встроенным плеером не открываются — только «скачать» / «В Finder»; «▶» есть у MP3 и общего экрана
- сводка о записи — тот же разбор, что у задачи: 4,5–6 с на запись из 18 дорожек (см. downloader, RESOLUTION)

## ПЕЧАТИ
Ъ — интерфейс загрузчика живёт в `ui/index.html`, `dashboard.html` в корне — дашборд канона, собирается xtask (25.09)

Ъ — техника загрузки (кусочки, дорожки, соединения, повторы, журнал) — только в свёрнутых «Подробностях» (28.09)
